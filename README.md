# Type4Taste

Type4Taste 是一个面向网站开发预览环境的字体试用工具原型。它允许设计者或开发者直接选取页面中的文字元素，根据内容角色查看字体建议，并在真实页面中即时切换、比较和还原字体。

当前示例包含：

- 双语内容页，用来展示标题、正文、品牌字标、界面文字和代码等不同字体场景
- 页面元素点选与当前排版参数读取
- 基于内容角色的本地字体推荐
- Google Fonts 与 ZSFT 免费商用字体目录
- 单个元素或同类内容的批量试用
- 字体搜索、实时加载、应用和还原
- 为后续 Agent Bridge 预留的交接入口

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端输出的本地地址，点击右下角 `Type4Taste`，再选择页面中的任意文字。

## 验证

```bash
npm run typecheck
npm run build
```

## 下一阶段

当前推荐由内置字体元数据和内容角色规则生成。Agent Bridge 将负责把页面上下文、选中文本与视觉目标交给正在构建项目的 Agent，再将 Agent 给出的候选字体传回预览界面；插件本身不必持有 LLM 密钥。
